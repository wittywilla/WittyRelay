Set the admin password

Choose a password for this relay's admin page.

{{if not .Secure}}

This page isn't open over HTTPS or from this machine, so the browser won't keep you signed in. Open it at http://localhost:8081 on the relay's machine, through an SSH tunnel, or behind a reverse proxy with HTTPS.

{{end}}

It's in the relay's log, printed when it started:
docker compose logs wittyrelay | grep "setup token"

At least 10 characters. A few words together is easy to remember and hard to guess.

Set it from the command line instead

On the relay's machine:

docker compose exec -T wittyrelay wittyrelay admin-password <<< 'your new password'

Then reload this page and sign in.

{{end}}
